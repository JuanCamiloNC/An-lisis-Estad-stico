# Tarea 2 Análisis Exploratorio e Inferencial

En este repositorio se encontrá con el desarrollo de los ejercicios que se encuentran en la guía de actividades. Además esto se hiso con el fin de mantener las normas APA 7 en el documento entregable.


## ¿Como funciona?

una vez dentro del repositorio podrá visualizar cada archivo:

- `Analisis.ipynb`
- `IC.ipynb`
- `PCC.ipynb`
- `PHCG.ipynb`
- `PVFF.ipynb`
- `TCL.ipynb`

Debe hacer click sobre el que quiere revisar y listo, se mostrán los resultados del ejercicio que selecciono.
